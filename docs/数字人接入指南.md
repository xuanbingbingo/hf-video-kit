# 数字人接入操作指南（2026-06-10）

> 接口契约：拿 `episode-NN/assets/voice.wav` 驱动一个形象，拿回一个 `avatar.mp4`
> （时长≈配音、人脸居中、背景干净），覆盖 `hf-project/assets/avatar.mp4`，重渲染。
> composition 零改动（圆窗 object-fit:cover，任意宽高比都行）。
> ⚠️ 本指南写于搜索故障会话，各平台界面/资费细节未核实，以实际页面为准。

## 第 0 步：准备要上传的文件（本机，1 分钟）

```bash
cd ~/aiProjects/avatar-hf-pipeline/episode-00
# 多数在线服务收 mp3 比 wav 稳，先转一份：
ffmpeg -y -i assets/voice.wav -b:a 192k assets/voice.mp3
```

要上传的就这一个文件：`assets/voice.mp3`（31 秒）。

## 路线 A：在线服务出第一条真数字人（本周目标，约半小时）

三选一，从上往下试：

### A1 腾讯智影（zenvideo.qq.com）
1. 微信扫码登录
2. 找「数字人播报 / 数字人视频」入口
3. 选一个公共数字人形象（先不要折腾自定义形象）
4. 驱动方式选「音频驱动」，上传 voice.mp3（如果只支持文字驱动 TTS，这家就放弃，换下一家——必须用我们自己的音频，否则时间轴全废）
5. 画面里只留数字人本体，背景选纯色，删掉模板自带的字幕/贴纸/背景音乐
6. 导出 1080p mp4，下载

### A2 蝉镜（chanjing.cc）— 同样流程
### A3 HeyGen（heygen.com）— 免费档有水印+时长限制，垫底备选

**红线**：必须支持「上传音频驱动」；导出必须能去掉平台自带字幕（我们的字幕在 hf 里）。

## 拿回 mp4 之后（本机，5 分钟）

```bash
cd ~/aiProjects/avatar-hf-pipeline/episode-00
# 1. 核对时长（和 31.0s 差距 >0.3s 就先别动，发给 Claude 调）
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 ~/Downloads/下载的数字人.mp4
# 2. 覆盖占位素材
cp ~/Downloads/下载的数字人.mp4 hf-project/assets/avatar.mp4
# 3. 重渲染
cd hf-project && npx hyperframes render --output ../ep00-avatar.mp4
open ../ep00-avatar.mp4
```

人脸如果在圆窗里偏了/太小：把视频发给 Claude，调一下 object-position 或预裁剪，一分钟的事。

## 路线 C：剪映数字人（备选，纯手工）

## 验收标准（任何路线通用）

- [ ] 口型和 voice.wav 对得上（播放时盯"数字人"三个字的口型）
- [ ] 时长和配音差距 < 0.3s
- [ ] 人脸在画面中央，圆窗裁切后五官完整
- [ ] 无平台水印、无平台字幕、无背景音乐
- [ ] 商用前确认平台条款/模型 license 允许
